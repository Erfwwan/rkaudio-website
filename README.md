# RK Audio Website

A premium bilingual landing page for RK Audio, built with Next.js App Router and TypeScript.

**The silence between the notes.**

## Languages
- Persian: `/fa` (RTL)
- English: `/en` (LTR)

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000. The root redirects to `/fa`.
